# Full study execution protocol

Frozen before full-study outcomes were inspected, 31 October 2026. This is an exploratory extension of a previously inspected pilot, not a preregistered independent confirmation.

All 309 original per-capture CSVs in the official CICIoT2023 CSV.zip are scanned. A deterministic reservoir retains at most 1,000 observations per file, and exact duplicate feature vectors within the retained source cohort are removed. Within each family with multiple files, the final lexicographic quarter (at least one file) is held out as whole files. Singleton-file families occur only in training. File groups are capture chunks, not independently collected devices or sessions. The four benign source files permit one held-out benign file; this is stronger than the initial within-file pilot but still limited.

All 51 official CICIoMT2024 training CSVs are scanned and capped at 1,000 rows per file to form an unlabeled acquisition pool. Labels are hidden from acquisition; acquisition uses only features and frozen source scores. The pool is a capped-capture population, not a random sample of natural deployment traffic. Inclusion correction targets that pool and does not correct an arbitrary change in target-test class prior.

All 21 official target-test CSVs are read completely. Exact feature duplicates against retained source training and acquisition pool, and repeated vectors within target test, are removed sequentially. This defines a unique-feature-vector test estimand; it does not estimate traffic-volume-weighted production risk. Keep raw and retained counts for each file. No cap is applied to target-test rows. Exclusion against all original unsampled source/training rows and near-duplicate detection are outside this protocol; report this boundary.

Feature alignment uses the common numeric header intersection excluding identifiers and labels. Time_To_Live in source is NOT silently mapped to Duration in target. One shared provider and similar names do not prove identical extraction semantics. Supplementary extraction code and headers are audited, and unresolved window semantics remain an explicit limitation. The primary claim is transfer between the distributed CSV representations, not a causal estimate of environment change alone.

Models: logistic regression C=1/max_iter=1000; random forest 150 trees/min_samples_leaf=5; histogram boosting 120 iterations/15 leaves/L2=1. Source preprocessing is signed-log1p, median imputation in transformed space, RobustScaler, clipping to [-100,100]. Model/preprocessing are frozen on target.

Five fixed seeds: 11,23,37,53,71. Four independent per-run budgets: 25,50,100,250. Methods: uniform random, entropy-only, greedy k-center, no-coverage-floor, no-entropy-allocation, no-inclusion-weights, proposed. Main K=8; RF seed-11 sensitivity K=4,16 is secondary and does not select the reported configuration. All selected IDs, labels, weights, objective history, optimizer status, and parameters are logged. Primary comparison is proposed versus random on held-out Brier/NLL at B=100, plus normalized log-budget loss integrals. Operational metrics use threshold 0.5 fixed before target-test evaluation. A constant source-training prior is a zero-target-label baseline.

Source raw scores are stored for all test rows. Positive-slope calibration preserves source ranking; AP/AUROC are reported as the source-ranking diagnostic and reused across calibrators to avoid interpreting numerical tie changes as improved discrimination. Probability loss, confusion counts, MCC, macro-F1, and ten disjoint equal-width-bin ECE are recomputed. This disjoint-bin ECE corrects the earlier pilot's floating interval-boundary ambiguity; the pilot is preserved unchanged and is not pooled with this run.

At B=100 retain per-capture outcomes for every model, seed, and method. Report capture-bootstrap paired Brier differences conditional on these files; independent files and seeds are not equivalent to independent domains. Only one benign target-test file is available, so false-alarm external-validity confidence cannot be estimated from this design. No significant or necessary-component claim is made merely because a seed mean improves. A component with identical allocation/results is not empirically essential.

No new algorithm, first-in-world status, causal effect, or demonstrated superiority is assumed. If outcomes fail to support the original novelty proposition, rewrite the manuscript around the measured limits of label-efficient calibration and retain the negative results. Completion means finishing acquisition/audit/experiments/analysis/documents, not forcing positive results.

A target-only diagnostic reference is trained once per model family (seed 11) using every retained target-pool label. Its explicit label cost equals the pool size. It uses the same source-fitted preprocessing to isolate model fitting rather than introducing target-test-fitted normalization. It is not a fair equal-budget competitor and does not change any main acquisition run. This reference tests whether the retained representation contains target-discriminative signal beyond what a frozen source score can expose.

Hashing uses a common float64 representation before comparison, preventing integer-versus-floating dtype differences from concealing exact numeric duplicates. The original capped-domain cache is retained for provenance, while full-study partition hashes are recomputed under this shared dtype.
