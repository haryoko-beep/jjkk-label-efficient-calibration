# Protokol revisi tuning eksploratori

Dibekukan sebelum hasil run tuning dibaca. Dataset test resmi telah dilihat pada studi sebelumnya; seluruh evaluasi tambahan pada test itu adalah exploratory reuse, bukan holdout independen baru. Tidak ada klaim confirmatory atau jaminan sasaran tercapai.

Gunakan partisi hash source_train/source_holdout/target_pool hasil studi lengkap. Source_holdout sebelumnya dilihat; sekarang hanya development validation sumber. Pisahkan source_train lagi menjadi 80/20 stratified development fit/validation menggunakan seed 20261101; source_holdout digunakan diagnostik terpisah, bukan memilih hasil test. Model fit sumber menggunakan semua benign yang tersedia dan maksimum 30.000 attack, dipilih acak tetap. Ini undersampling berlabel sumber, dinyatakan terbuka.

Grid sumber: fitur irisan penuh; indikator protokol/flag/count; statistik panjang paket. Subset adalah diagnostic compatibility proxy, bukan sertifikasi satuan/extractor. LR C=0.1,1 dan class_weight=None/balanced; RF 120 trees min_samples_leaf=5,20 dan class_weight=None/balanced. Semua kandidat memakai imputer/scaler source-fit dan clipping tetap 100; clipping per domain dilaporkan. Pilih satu kandidat per model-family menggunakan source development recall pada threshold dengan validation FPR<=5%, tie-break AUROC lalu fewer features. Threshold ditetapkan dengan aturan empirical benign upper-tail order statistic, bukan ROC test. Laporkan uncertainty FPR; batas empiris bukan jaminan populasi.

Lima seed 11,23,37,53,71; B total target=100,250,1000. B=1000 adalah perluasan budget terpisah, tidak dibandingkan seolah 100 label. Setiap budget membagi 60% label acquisition/adaptation dan 40% random validation. Query validation diambil acak tanpa memakai label, dikeluarkan dari adaptation candidate pool; label validation tidak boleh melatih adaptasi. Validation sample sama untuk semua metode dalam model-seed-budget. Semua label dihitung dalam B; semua query menyimpan hash.

Adaptation selectors: random dan stratified entropy/coverage (aturan lama) untuk weighted calibration; ablation no_weights dan no_entropy dengan budget sama; target-only balanced RF memakai query random/proposed yang sama; source+target RF memakai source fixed subsample + query dengan domain weights 50:50 sebelum pengalian class_weight balanced global. Karena class weighting global dapat mengubah massa domain efektif, jangan menyebut bobot akhir sebagai tepat 50:50. Intercept-only sigmoid calibration memakai random query sebagai kontrol. Source classifier frozen untuk seluruh kalibrator. Calibrated/native threshold 0.5 dan threshold target-validation 5% serta 1% dilaporkan. Source threshold transfer juga diuji. Tidak ada cutoff dipilih dari test.

Threshold target validation memakai seluruh benign validation yang kebetulan terquery. Jika nol benign, fallback source threshold untuk native source score; untuk metode adapted gunakan threshold infinity sebagai refusal-to-alert control. Kegagalan dan fallback dicatat. Jumlah benign kecil tidak dianggap cukup untuk klaim kontrol FPR. Threshold empirical 1%/5% dapat sama pada sampel kecil; sertakan jumlah benign dan upper confidence bound exact binomial untuk error validation. Model all-benign/all-attack dinilai bersama recall/MCC, tidak disebut sukses karena satu metrik.

Sasaran evaluasi bersama FPR<=5% dan recall>=80%; alternatif FPR<=1% dilaporkan terpisah. Tidak mengoptimalkan jumlah seed yang lolos. Semua candidate selection terjadi sebelum test ditransformasi/diprediksi. Simpan grid validation, model pilihan, label accounting, optimizer log asli, skor raw test dan koefisien, threshold, test metrics class-conditional losses, balanced Brier/NLL, dan family recall. Hasil eksploratori ini tidak membuktikan novelty jika retraining sederhana mengungguli desain usulan atau ablation komponen tidak positif.
